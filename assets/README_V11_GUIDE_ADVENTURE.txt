EMX Soul Arena v11 — Guide + Adventure Update

Install:
1. Open this folder.
2. Copy everything inside emx_soul_arena_v11 into your GitHub repo root.
3. Your repo root should contain index.html, style.css, script.js, manifest.webmanifest, multiplayer files, firebase files, and assets/.
4. Commit and push to GitHub.
5. Wait for Vercel to redeploy.

New systems:
- Guided Tutorial Mode
- Next Goal helper button
- EMX Bot guide tips
- Guide Quest Board with claimable rewards
- Power Guide explaining costs, unlock levels, and best use
- Boss Warning System with damage reduction when countered
- Adventure Rooms between fights
- Gear Forge permanent gear upgrades

Sound note:
Sound files are still included from v10, but iPhone/Safari can be strict about audio. This update does not depend on sound working.
