EMX Soul Arena v15 - Full Button Restore

This update keeps the v14 game and adds a stronger tap controller.
It fixes cases where Safari/Home Screen or hidden UI layers cause buttons to make sound but not run their actions.

Install:
1. Open emx_soul_arena_v15.
2. Copy everything inside that folder into the repo root.
3. Make sure index.html, style.css, script.js, tapfix.js, manifest.webmanifest, multiplayer files, firebase files, and assets/ are all in the root.
4. Commit and push.
5. Wait for Vercel redeploy.
6. Hard refresh Safari. If Home Screen is still frozen, delete the old Home Screen icon and add it again.
